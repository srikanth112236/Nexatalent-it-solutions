# Public Website Build Specification

## Website objective

The public website must:

1. Explain NexaTalent clearly.
2. Build employer trust.
3. Help candidates find opportunities.
4. Demonstrate recruitment expertise.
5. Convert employer hiring demand.
6. Support SEO/content growth.
7. Provide a polished gateway into authenticated portals.

## Five homepage directions

### V1 — Premium Recruitment Platform

Strong technology-enabled recruitment positioning. Large editorial hero, workflow visualization, proof, services and CTA.

### V2 — Human + Technology

Human expertise is the emotional anchor; technology appears as the system that creates visibility and consistency.

### V3 — Enterprise Recruitment

More structured, data-driven and enterprise-oriented. Focus on scale, governance, process and reporting.

### V4 — Editorial Premium

Magazine-like typography, storytelling, whitespace, photography and strong case-study narrative.

### V5 — Conversion First

High clarity, shorter sections, strong employer/candidate split, immediate hiring CTA and job discovery.

## Page templates

### Solution

Hero → Problem → Audience → Approach → Capabilities → Process → Proof → FAQ → CTA

### Industry

Hero → Industry context → Hiring challenges → Roles → Solutions → Proof → Jobs → Insights → CTA

### Job

Job summary → Responsibilities → Requirements → Skills → Benefits → Process → Apply → Related jobs

### Insight

Title → metadata → content → related insights → related jobs/solutions → CTA

### Case study

Challenge → context → requirement → approach → execution → result → testimonial → CTA

## Website rule

The website should be fully usable before portal development begins.
