# Foundation Component Library

Build these before any page-specific work.

## Primitive components

Button, IconButton, Link, Text, Heading, Label, Badge, Tag, Divider, Avatar, Image, Container, Stack, Grid, Section, AspectRatio, Spacer.

## Form primitives

Input, Textarea, Select, MultiSelect, Checkbox, Radio, Switch, DatePicker, FileUpload, SearchInput, FormField, FormError, FormActions.

## Feedback

Alert, Toast, Tooltip, Skeleton, Spinner, Progress, EmptyState, ErrorState, SuccessState.

## Overlay

Modal, Dialog, Drawer, Popover, DropdownMenu, ContextMenu, ConfirmationDialog.

## Navigation

Header, MobileHeader, Breadcrumbs, Tabs, Pagination, Sidebar, PortalSidebar, Footer, MegaMenu.

## Data display

Card, StatCard, Table, DataTable, List, Timeline, Accordion, Stepper, AvatarGroup.

## Rule

Do not build page-specific Button, Card, Input, Modal or Table implementations.

Extend the shared component when a real variant is required.
