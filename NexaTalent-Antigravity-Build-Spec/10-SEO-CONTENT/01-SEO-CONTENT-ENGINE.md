# SEO and Content Engine

## Technical SEO

Implement:

- unique title
- meta description
- canonical URL
- Open Graph metadata
- Twitter/social metadata
- semantic heading hierarchy
- XML sitemap
- robots.txt
- clean URLs
- breadcrumbs
- structured data where valid

## Schema types

Use only when accurate:

- Organization
- WebSite
- BreadcrumbList
- JobPosting
- Article
- FAQPage where the content qualifies
- LocalBusiness only when genuinely applicable

## Content entities

Page, Article, Guide, Report, Case Study, Job, Industry, Solution, Location, Testimonial, FAQ and Resource.

## SEO templates

### Job

`[Job Title] in [Location] | NexaTalent`

### Solution

`[Recruitment Solution] | NexaTalent`

### Industry

`Recruitment for [Industry] | NexaTalent`

### Location

`Recruitment & Jobs in [Location] | NexaTalent`

## Internal linking

Industry → Solution → Case Study → Insight → Job → Contact.

Article → Guide → Jobs → Job Detail → Application.

Hiring Guide → Solution → Case Study → Hire Talent → Form.

## Content governance

Draft → Review → Approved → Published → Updated → Archived.

All claims must be traceable to approved source material.
